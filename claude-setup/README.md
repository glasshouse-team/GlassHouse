# Install the Claude Code and GitHub config (once)

This folder holds the files Claude Code and GitHub read from hidden locations: `.claude/`, `.mcp.json` and `.github/`. Remote tools are not allowed to write those locations on your Mac (so nothing can install hooks, MCP servers or CI workflows without you), so they wait here until you move them into place.

Run this once in Terminal, before `git init`:

```bash
cd ~/Desktop/glasshouse
mv claude-setup/dot-claude .claude
mv claude-setup/dot-github .github
mv claude-setup/mcp.json .mcp.json
rm -r claude-setup
```

What you are installing:

| Goes to                                             | What it is                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| --------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `.claude/skills/`                                   | 16 project skills: `start-ticket`, `finish-ticket`, `record-decision` (logs a changed decision and updates the affected Jira tickets) and 13 domain skills (reverse-engineer-airbnb, shared-contracts, marble-world-pipeline, splat-tour-viewer, floor-plan-geometry, verifier-vision, agent-builder, negotiation-engine, ...)                                                                                                                                                                                                         |
| `.claude/rules/`                                    | Short rules that load when Claude edits matching files (contracts, money, 3D, agents, API routes)                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `.claude/agents/pr-reviewer.md`                     | A review subagent used by `finish-ticket`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `.claude/hooks/`                                    | Three Node scripts Claude Code runs: `session-context.mjs` at session start (says who you are and which ticket your branch is), `ownership-guard.mjs` before file edits (asks before Claude edits the other developer's files) and `decision-nudge.mjs` after edits to contract or decision files (reminds Claude to run `record-decision`; keeps a small list in your temp folder so it reminds once per file). They read only this repo's files and the current git branch, use no network, and write nothing except that temp list. |
| `.claude/settings.json`                             | Turns the hooks on, allows `pnpm check`-style commands, blocks reading `.env` files                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `.claude/settings.local.json`                       | Your identity for the hooks: `GLASSHOUSE_DEV=temuri` (git-ignored; Beka copies `settings.local.example.json` and sets `beka`)                                                                                                                                                                                                                                                                                                                                                                                                          |
| `.claude/ownership.json`, `.claude/ticket-map.json` | Data for the hooks and skills                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `.mcp.json`                                         | The Atlassian (Jira) MCP server, `https://mcp.atlassian.com/v2/mcp`. Claude Code asks before enabling it; log in with `/mcp`                                                                                                                                                                                                                                                                                                                                                                                                           |
| `.github/`                                          | CI workflow (typecheck, lint, test, build), PR template, CODEOWNERS template                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
