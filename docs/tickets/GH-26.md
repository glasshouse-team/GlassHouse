- Publish v1 with `publishWorld()` (lib/marble-worlds.ts, GH-10): set `published_world_id`, move other published hero-1 worlds to `ready`, and set v1's `requested`/`filled` gaps back to `open`.

- The 1.5 s negotiation pause lives in GH-15; implement it once.

## Goal
The demo can be run, reset and run again in seconds, with no live generation and no leftover state. Everything is checked against one list.

**When:** hours 18–20 · **Estimate:** 1.5h · **Depends on:** all must-haves

## Build
1. **`DEMO_MODE=true` behavior**, checked in every relevant route:
    - No calls to World Labs; generation returns saved versions.
    - Negotiation turns pause 1.5 s.
    - Seeded dates are fixed.
2. **`pnpm demo:reset`** (`scripts/reset-demo.ts`):
    - Delete demo deals, deal messages, reservations, Q&A messages and events created after the seed.
    - Restore the hero policy, publish Hero 1 v1 (the gap version), and clear the forwarded-question answer from the manual.
    - Print "Demo ready".
3. **Pre-flight page** `/demo/check`: green or red for env vars, Supabase connection, both hero worlds loading, the X-ray rows, and a Claude API ping.
