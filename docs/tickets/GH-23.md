## Goal
On arrival, the guest films 30–60 seconds. The Verifier compares it with the listing and reports matches and differences. This closes the trust loop ("it really solves the problem").

**Start only after GH-17 says all should-haves are done.** · **Estimate:** 2h · **Depends on:** GH-9, GH-10; the GH-22 recorder if it exists (a plain file input otherwise)

## Build
1. **Trip page** `/trip/[reservationId]` (`app/(guest)/trip/`): reservation details and a "Film your arrival" button (file input with `capture="environment"`, or the GH-22 recorder in `checkin` mode).
2. **`POST /api/checkin`:**
    - Extract about 12 frames (reuse Temuri's `lib/media.ts` read-only).
    - For each frame, match the room. The Verifier (Sonnet 5.5) compares it with the listing photos and world screenshots of that room.
    - Zod report: `matches[]`, `differences[{room, listed, seen, evidence_frame, severity}]`, `missing_items[]`.
    - Only visible facts; no guesses about cleanliness beyond what the frames show.
3. **Outputs:**
    - The guest sees the report; the host is notified; an event is logged.
    - Severe differences show "Open an issue" (the deposit escrow idea stays on a slide).
4. **Privacy:** check-in videos go to the private `captures` bucket.

## Acceptance criteria
- [ ] With the staged check-in clip from GH-6 (a moved chair or lamp), the report lists that difference and nothing major that's false.
- [ ] The report renders on a phone.
