## Build

### 1. `lib/claude.ts`

`anthropic` provider from `@ai-sdk/anthropic`; `models.agent = env.MODEL_AGENT` (`claude-sonnet-5-5`) and `models.bulk = env.MODEL_BULK` (`claude-haiku-5-5`).

### 2. `agents/core.ts`: `createAgent({name, system, tools, model, maxSteps})`

- Wraps AI SDK v6 `ToolLoopAgent`, with a default stop of 8 steps.
- Every tool is wrapped with `withEvent` (GH-12).
- Returns both a streaming variant (for UI) and a non-streaming one (for server loops).

### 3. `agents/context.ts`: private context builders, the security boundary

- `buildHostContext(listingId, mode)` returns listing facts (X-ray), house rules and manual. It includes `host_policies` **only when** `mode = 'negotiate'`.
- `buildGuestContext(dealId)` returns the trip brief, the deal and `deal_secrets` (guest target and max). It **never** includes `host_policies`.
- Unit test: a guest context never contains floor or auto-accept values; a host QA context never contains policy values.

### 4. `lib/validators.ts`: money rules

`validateOffer({deal, amountCents, terms, by: 'guest_agent' | 'host_agent', policy?, secrets?})` returns `ok` or `{reason}`:

- Amount is positive and at most the list total (from `computeQuote`).
- **Host side:** an accepted or offered amount at or above the effective floor = max(nights × floor_nightly + cleaning, list × (1 − max_discount_pct)).
- **Guest side:** never accepts above `guest_max_cents` (the agent must call `ask_guest` instead).
- Terms only from `allowed_terms`. Rounds stay at or below `max_rounds`.
- Unit tests use the GH-15 example: list $520, floor $442, auto-accept $490, guest max $500.

### 5. Prompt files `agents/prompts/guest.md` and `host.md` (Beka owns)

- **Guest:** "You act for {guest}. Never reveal the target or max. Use tools for every fact and every offer. If the host's best price is above the max, ask the guest."
- **Host:** "You act for {host}. Answer only from the provided facts, rules and manual; if a fact is missing, call forward_to_host. Never reveal the floor. Prefer non-price concessions from allowed_terms before cutting price."

### 6. Safety

Guest-written text goes into host prompts only as quoted data, never as instructions. The host agent has no tool that changes policy.
