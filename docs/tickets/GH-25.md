## Goal
The host talks while filming ("This is the bedroom, the bed is new"), and the host agent drafts the listing from the transcript, the frames and the X-ray facts.

**Only if ahead of schedule.** · **Estimate:** 1.5h · **Depends on:** GH-9, GH-13; a capture with audio (GH-22, or an uploaded video)

## Build
1. **Transcription:** Web Speech API or the audio track of the uploaded video. Use ElevenLabs Scribe for Georgian (strong reported accuracy).
2. **`POST /api/listing-draft`:** the host agent's `draft_listing` tool (Haiku 5.5) returns title, description, amenities and house rules, plus a "missing photos" list from the X-ray.
3. **UI** on the host dashboard: an editable draft; saving updates the listing; every change logs an event.

## Acceptance criteria
- [ ] A 60-second narrated walkthrough produces a usable draft in under 20 seconds, in English and in Georgian.
