## Goal
Inside the tour, the guest asks "Where would I work?" or "Can I see the mountains from bed?". The guest agent answers from facts and **moves the camera there**, so the 3D becomes something the agent uses, not decoration.

**When:** hours 13–15 · **Estimate:** 2h · **Depends on:** GH-11 (`useTour()`), GH-13, GH-9; object anchors from GH-19 (manual anchors work until then)

## Build
1. **Panel** `components/tour-ext/AskSpacePanel.tsx`:
    - A chat overlay inside the tour, with suggested questions.
    - It uses only `useTour()`. **Do not edit `components/tour/`.**
2. **`POST /api/ask-space`** (streaming): the guest agent (`createAgent`) with context = listing facts + `anchors` (names, kinds, rooms) + open `gaps`.
3. **Tools** (`tools/guest/space.ts`). These return **actions** that the client executes through `useTour()`:
    - `fly_to(anchorId)`
    - `look_toward(anchorId | point)`
    - `highlight_room(name)`
    - `show_fact(factKey)`
4. **Example behaviors:**
    - "Where would I work?" → desk anchor + "desk near window" fact → `fly_to(desk)` → "Here, by the window, about 1.5 m from the balcony door."
    - "Can I see the mountains from bed?" → `fly_to(bed)` → `look_toward(window)`.
5. **Honesty in answers:** if an anchor is within 1.5 m of an open gap, the answer says "That area is partly AI-filled; the host hasn't filmed it yet."
6. **Events:** "Guest agent showed Nino the workspace".
