## Build notes

- Spheres: `MeshBasicMaterial({ color: "#f5a524", transparent: true, opacity: 0.35, depthWrite: false })` with `mesh.raycast = () => {}` so they don't block walking rays; add them with `useTour().addOverlay`.
- Tint upgrade: in Spark 2.3 a `SplatEdit` outside any SplatMesh applies to all splats in world space, so `addOverlay(edit)` with `SplatEditSdf` spheres at each gap works.
- `CoverageBadge({ score: number | null })` renders nothing for null. Embed with `worlds!listings_published_world_fk(coverage_score)`: two foreign keys join the tables, so a plain embed is ambiguous.
- Test the kitchen corner on v1 and v2 rather than "nothing on v2" (GH-19 may find other gaps). No "How we verify" page exists yet: link to a short section on the listing page, or drop the link.

## Goal
One toggle, "Show what's real", visibly marks the AI-filled areas in the 3D. Every listing shows a coverage score. Trust becomes something the guest can see.

**When:** hours 15–17 · **Estimate:** 1.5h · **Depends on:** GH-11 (`useTour().addOverlay`), GH-19 (`gaps`, `coverage_score`)

## Build
1. **Overlay** `components/tour-ext/HonestyOverlay.tsx`:
    - **Start with the fallback:** for each open gap, a translucent amber sphere (radius = `radius_m`) added via `useTour().addOverlay()`.
    - **Upgrade if time allows:** tint the splats inside each sphere using Spark's splat color editing (check its edit API in the docs and examples).
    - A toggle button "Show what's real" and a small legend: "Amber = AI-filled, not filmed by the host".
2. **Coverage score badge:**
    - On search cards (GH-8) and the listing page: "92% filmed" style, read from the published world's `coverage_score`.
    - A tooltip explains what it means and links to "How we verify".
3. **Floor plan hatching** is done by Temuri in GH-18 from the same `gaps` data. Coordinate the color with him.
4. **Events:** toggling isn't logged (too noisy); the score comes from the Verifier event in GH-19.
